## 🔄 Updating the Portfolio

This portfolio is intended to be continuously updated.

When I complete a new project, I can:

1. Create a GitHub repository for the project.
2. Add a README and supporting documentation.
3. Add screenshots or other evidence.
4. Add the project information to `script.js`.
5. Add the project card to the portfolio.
6. Deploy the updated website.

For a new certificate or achievement:

1. Add the PDF to the appropriate folder.
2. Add the achievement information to `script.js`.
3. Link the PDF from the generated card.
4. Deploy the updated website.

This allows the portfolio to grow without having to redesign the entire website every time new work is added.
